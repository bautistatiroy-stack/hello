WATER MONITORING DASHBOARD SPLIT

Folders:
- index.html / style.css: main page for choosing a dashboard
- barangay/: Levels 1-3
- river/: Levels 4-6

IMPORTANT:
The uploaded source contained the HTML and JavaScript, but did not include the original
dashboard style.css file. The barangay.css and river.css files import ../style.css.
To preserve the exact original dashboard appearance, copy your original dashboard
style.css into the WaterMonitoring root folder, replacing the selector-only style.css
provided here. If you do that, keep the main selector styles by appending them to the
same stylesheet or save them separately.

The Google Apps Script API URL is retained from the uploaded code.
Both dashboards request the same Google Sheets data and display only their assigned
three sensor levels.
